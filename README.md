# MeepLab.gg

The champ select lab under Targon's stars. MeepLab.gg reads your League of Legends champ select and tells you what the draft really says: your team's odds, the picks that fit, the bans that hurt them, lane swaps, Clash scouting and a plan for the game. Free for macOS and Windows.

**Download:** https://meeplab-gg.vercel.app, or from the [latest release](https://github.com/13rianVargas/MeepLab.gg/releases/latest):

- macOS 15+ (Apple Silicon and Intel): `MeepLab.gg-macOS.dmg`. Open it and drag MeepLab.gg to Applications. The first time, open it, then go to System Settings → Privacy & Security and click Open Anyway.
- Windows 10 and 11: `MeepLab.gg-Windows.exe`. One portable file. If SmartScreen appears: More info → Run anyway.

**Updates** install themselves. Every update is signed and checked before it's installed. To try new versions first, turn on *Get beta versions* in Settings → Updates.

This repository holds the downloads and the website (`site/`). The app's source code is private.
