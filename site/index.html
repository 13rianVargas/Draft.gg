✦ Questions from the summit

Is it allowed?

MeepLab.gg only reads what the League client and the game already show you, through Riot's own local interfaces. It doesn't read the game's memory, doesn't track enemy cooldowns and never tells you what to do mid-game.

Do I need an account or an API key?

No. Open League and MeepLab.gg connects on its own and imports your recent games. A Riot API key is optional, only to import older games.

How do updates work?

The app checks for new versions every few hours and installs them by itself. Every update is signed and checked before it's installed.

macOS says it can't check the app

MeepLab.gg isn't sold on the App Store. The first time, open it once, then go to System Settings → Privacy & Security and click Open Anyway. Or skip that: install it from Terminal with the command under the download button. After that it opens normally and updates itself.

Windows shows "Windows protected your PC"

That's SmartScreen for new apps. Click "More info", then "Run anyway". It's a single portable file: no installer, nothing else to set up.
